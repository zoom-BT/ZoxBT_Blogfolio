## 📖 About this Course

**Introduction to DAX Analysis with Power BI** is a course by **DataCoach.ca**, dedicated to the DAX language (Data Analysis Expressions) to deepen data analysis in Power BI.

## 📚 Course Content

- DAX language fundamentals
- Creating measures and calculated columns
- Aggregation and filter functions
- Row context and filter context
- Time intelligence analysis

## 🎯 Skills Acquired

- Write DAX formulas for advanced measures
- Understand DAX evaluation contexts
- Build time-based analyses in Power BI
- Optimize data models for analysis

This course rounds out my Power BI training, giving me the tools to go beyond simple visualizations and build advanced business analyses.
