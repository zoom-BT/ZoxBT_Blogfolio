## 📖 About this Course

**Unsupervised Learning, Recommenders, Reinforcement Learning** is the third and final course of Andrew Ng's **Machine Learning Specialization**, taught by the co-founder of Coursera and DeepLearning.AI, professor at Stanford.

## 📚 Course Content

### Unsupervised Learning
- Clustering with the K-means algorithm
- Anomaly detection (Gaussian distribution)
- Supervised vs. unsupervised learning comparison

### Recommender Systems
- Collaborative filtering
- Content-based filtering with neural networks
- Principles of a large-scale recommender system (e.g. PCA)

### Reinforcement Learning
- Reinforcement learning formulation (states, actions, rewards)
- Markov Decision Process
- Deep Q-Learning (algorithm and implementation)
- Guided project: lunar lander landing (Lunar Lander)

## 🎯 Skills Acquired

- Implement K-means clustering and anomaly detection
- Build a recommender system (collaborative and content-based filtering)
- Understand and implement a reinforcement learning agent
- Apply Deep Q-Learning to a control problem

## 🏆 Impact on My Journey

This final course broadened my understanding of Machine Learning beyond supervised learning: recommender systems and reinforcement learning open concrete perspectives for future projects.
