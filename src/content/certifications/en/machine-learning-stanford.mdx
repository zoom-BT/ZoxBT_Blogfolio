## 📘 Description

Le cours de **Machine Learning de Stanford** est considéré comme l'un des meilleurs cours d'introduction au ML. Enseigné par Andrew Ng, il couvre les fondamentaux théoriques et pratiques.

## 📚 Contenu du Cours

### Supervised Learning
- Linear Regression
- Logistic Regression
- Neural Networks
- Support Vector Machines (SVM)

### Unsupervised Learning
- K-Means Clustering
- PCA (Principal Component Analysis)
- Anomaly Detection

### Machine Learning Systems
- Recommender Systems
- Large Scale Machine Learning
- Application Example: Photo OCR

## 🎯 Concepts Clés

- Gradient Descent et optimisation
- Bias-Variance tradeoff
- Regularization (L1, L2)
- Model evaluation et validation
- Learning curves
- Error analysis

## 💡 Pourquoi ce Cours?

Ce cours a été mon **premier pas** dans le ML:
- Explications claires et intuitives
- Bon équilibre théorie/pratique
- Projets stimulants
- Fondations solides pour approfondir

## ⭐ Recommandation

Je recommande vivement ce cours à tous ceux qui veulent débuter en ML. C'est un excellent point de départ avant d'aborder le Deep Learning.
