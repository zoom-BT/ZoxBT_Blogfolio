- Cost Function (Fonction de Coût)
- Gradient Descent

**Implémentation:**
```python
# Régression linéaire simple
def compute_cost(X, y, w, b):
    m = X.shape[0]
    cost = 0
    for i in range(m):
        f_wb = w * X[i] + b
        cost += (f_wb - y[i])**2
    total_cost = cost / (2 * m)
    return total_cost
```

### Semaine 2: Régression Linéaire Multiple

**Concepts:**
- Multiple Features
- Vectorisation
- Gradient Descent pour Multiple Variables
- Feature Scaling
- Learning Rate

**Implémentation:**
```python
def gradient_descent(X, y, w_init, b_init, alpha, num_iters):
    w = w_init
    b = b_init

    for i in range(num_iters):
        # Calculer les gradients
        dj_dw, dj_db = compute_gradient(X, y, w, b)

        # Mettre à jour les paramètres
        w = w - alpha * dj_dw
        b = b - alpha * dj_db

    return w, b
```

**Sigmoid Function:**
```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def predict(X, w, b):
    z = np.dot(X, w) + b
    f_wb = sigmoid(z)
    return f_wb >= 0.5
```

### Semaine 4: Régularisation et Overfitting

**Concepts:**
- Problème d'overfitting
- Underfitting vs Overfitting
- Régularisation L2 (Ridge)
- Regularised Linear Regression
- Regularised Logistic Regression

**Régularisation:**
```python
def compute_cost_reg(X, y, w, b, lambda_):
    m = X.shape[0]
    cost = compute_cost(X, y, w, b)

    # Terme de régularisation
    reg_cost = (lambda_ / (2 * m)) * np.sum(w**2)

    total_cost = cost + reg_cost
    return total_cost
```

## 🧠 Concepts Clés Maîtrisés

### 1. Gradient Descent
Algorithme d'optimisation fondamental:
```
Repeat {
    w = w - α * ∂J/∂w
    b = b - α * ∂J/∂b
}
```

### 2. Cost Function
- Mean Squared Error (MSE) pour régression
- Binary Cross-Entropy pour classification

### 3. Regularisation
Prévenir l'overfitting:
```
J(w,b) = J_original(w,b) + (λ/2m) Σw²
```
