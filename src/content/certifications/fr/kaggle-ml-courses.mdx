## 📚 Cours Complétés

### 1. Intro to Machine Learning
- Fondamentaux du ML
- Decision Trees
- Random Forests
- Model Validation
- Underfitting/Overfitting

### 2. Pandas
- Data manipulation
- DataFrames et Series
- Grouping et Sorting
- Data types et Missing Values
- Renaming et Combining

### 3. Intermediate Machine Learning
- Missing Values handling
- Categorical Variables
- Pipelines
- Cross-Validation
- XGBoost

### 4. Data Visualization
- Line Charts et Bar Charts
- Heatmaps
- Scatter Plots
- Distributions
- Seaborn et Matplotlib

### 5. Feature Engineering
- Mutual Information
- Creating Features
- K-Means clustering
- Principal Component Analysis (PCA)
- Target Encoding

### 6. Intro to Deep Learning
- Neural Networks basics
- Deep Learning fundamentals
- Stochastic Gradient Descent
- Overfitting et Underfitting
- Dropout et Batch Normalization

### 7. Computer Vision
- Convolutional Neural Networks (CNNs)
- Convolution et ReLU
- Maximum Pooling
- Data Augmentation
- Transfer Learning

### 8. Time Series
- Linear Regression with Time
- Trend
- Seasonality
- Time Series as Features
- Hybrid Models

### 9. Machine Learning Explainability
- Permutation Importance
- Partial Dependence Plots
- SHAP Values
- Advanced Uses of SHAP
- Model Interpretation

### 10. AI Ethics
- Human-Centered Design
- Identifying Bias
- Fairness Metrics
- Model Cards
- Responsible AI
